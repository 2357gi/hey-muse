## Jev の位置づけ

天気・予定の読み取り要求には、Jevによる言い換えの分類を追加しました。[設定と評価](jev-read-only.md)を参照してください。

家電操作については、Jev Choice を定型命令の分類候補として比較しました。12例の評価で引用を含む質問が消灯命令と判定されたため、家電の自動実行には接続していません。採用した経路は、端末内の明示的な定型句判定から認証済みの母艦 API へ送るものです。比較スクリプトはキーを標準入力から受け取り、家電へ命令する機能を持ちません。

同じ呼びかけ内の操作記録を通常会話に引き継ぎます。曖昧な操作、否定、引用、単なる「もう一回」はそのまま家電操作にしません。モニターの「つけて／消して」は、設定済みの電源切替シーンを1回送る仕様です。実際の電源状態を指定するものではありません。

## 設定

- `brain.muse.chat` を `"new"` にすると呼びかけごとのサイドチャットになります。固定IDまたはメインチャットも引き続き選べます。
- 継続会話の待ち時間と回数はウェイクワードの設定を使います。回数 `0` は上限なしで、無音時に待受を終えます。
- 天気は既存の場所設定、または `configure-weather -name ... -lat ... -lon ...` で地域を指定します。地域や端末シリアル番号はソースに固定しません。
- カレンダー、操作する機器・シーン、共有鍵、接続先は母艦と Echo のローカル設定です。[設定例](../tools/mothership/README.md)を参照してください。
- 母艦の音声 API のトークンは `SPEECH_BRIDGE_TOKEN` から読みます。Echo の音声プロバイダーにも同じ値を設定します。以前の実機用の固定ダミーキーは使用しません。

## 検証範囲

過去の実機試験では、日本語表示・認識、会話、家電操作、カレンダー、天気表示を確認しました。今回の統合では Go 全パッケージの自動テスト、会話処理の race テスト、Python 19テスト、Show / Spot / Dot の ARMv7 ビルドが通りました。端末・家電への実操作は統合テストに含めません。

個人の音声、予定、取得済みデータ、認証情報、機器ID、実機用の設定・バイナリは含めません。音声モデルの比較実験や個人向け追加学習は常用機能とは別であり、この統合でモデルを変更するものではありません。既存の日本語表示・ASRコミットとサイドチャットの履歴を保持して統合しています。
